# Spec: portfolio-data

## ADDED

### Requirement: timeline accuracy

Every entry in the About page timeline must reference only projects or milestones that currently exist in the portfolio. Removed or archived projects must not appear in timeline entries.

- Timeline years must reflect the actual year of the milestone, not outdated static values.

### Requirement: experience date ranges

Each experience entry must include a complete date range (start — end or start — Present). No experience entry may display only a single label like "Present" without a start date.

### Requirement: current year accuracy

Timeline and experience entries must display the current or most recent relevant year. Outdated years (e.g., showing 2024 when the current year is 2026) must be corrected.
