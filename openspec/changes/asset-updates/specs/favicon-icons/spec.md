# Spec: favicon-icons

## ADDED Requirements

### REQ-1: ICO Fallback Favicon

The site **SHALL** have a `.ico` fallback favicon served from `public/favicon.ico`.

### REQ-2: Apple Touch Icon

The site **SHALL** have an Apple touch icon served from `public/apple-touch-icon.png`.

### REQ-3: HTML References

The site **SHALL** reference both `favicon.ico` and `apple-touch-icon.png` via `<link>` tags in `index.html`.
