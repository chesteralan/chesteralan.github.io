# Spec: test-infrastructure

## Status: ADDED

## Requirements

- The project **SHALL** have Vitest configured as the test runner.
- The project **SHALL** have React Testing Library available for component testing.
- The project **SHALL** use the `jsdom` environment for running tests.
- Tests **SHALL** be executable via a `yarn test` command.
- The project **SHALL** provide a coverage report via a `yarn test:coverage` command.
