# Spec: skip-link

## Status: ADDED

## Requirements

- A skip-to-content link **SHALL** be the first focusable element in the DOM.
- A skip-to-content link **SHALL** be visually hidden until focused.
- A skip-to-content link **SHALL** link to the main content area via an anchor id.
- The skip link **SHALL** become visible with a clear visual style when focused via keyboard.
- The main content container **SHALL** have a matching anchor id (`#main-content`).
