# Implementation & Design Audit

## Goal

Comprehensive audit of the entire web app covering code quality and UI/UX. Produce a written report with findings and severity levels.

## Scope

All files under `apps/web/src/` — components, pages, data, lib, tests, styles.

## Audit Areas

### Implementation Audit

1. **Code quality** — unused imports, dead code, inconsistent patterns, type safety
2. **Bugs** — logic errors, race conditions, missing error handling
3. **Performance** — unnecessary re-renders, missing memoization, large bundle concerns
4. **Security** — XSS vectors, unsafe HTML injection, secrets in client code
5. **Tests** — coverage gaps, flaky patterns, missing edge cases

### Design Audit

1. **Visual consistency** — spacing, colors, typography, border radius, shadows across components
2. **Accessibility (a11y)** — ARIA labels, keyboard navigation, color contrast, focus states, semantic HTML
3. **Responsive design** — mobile/tablet/desktop breakpoints, overflow issues
4. **Icon consistency** — sizing, alignment, stroke weight after Lucide migration

## Approach

Read every source file systematically, cross-reference patterns, produce a structured report grouped by severity (critical / high / medium / low).

## Output

Write findings to `AUDIT-REPORT.md` at project root.
